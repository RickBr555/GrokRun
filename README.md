# GrokRun

Treino de tiros e corrida com pace, GPS, percurso e um jogo de pista. Interface em português do Brasil.

O site é a versão da prévia. O app Android nativo está em `android/`.

## Site

Precisa do Node.js 22.

```bash
npm install
npm run dev
```

Abre em http://localhost:8080.

Os desenhos dos bots ficam em `public/mascots/`.

## Android

Abra a pasta `android` no Android Studio. O passo a passo está em `android/README.md`.
